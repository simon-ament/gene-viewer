Every gene visualization description generated by a [`GeneViewer`](/python/gene-viewer) is stored as a JSON file at `<viewerId>/<geneId>.json` relative to the `dirPath` configured on the `GeneViewer`.

For example, information on the gene "AARS1" for a `GeneViewer` instance with identifier "df83316df83" would be stored in `df83316df83/AARS1.json`.

## Schema

Every such JSON file must adhere to the following type:

```ts
// types.ts
interface Gene {
    id: string;
    seq_id: string;
    start: number;
    end: number;
    strand: "+" | "-";

    species: string | null;
    source: string | null;
    
    probes: Probes;
    regions: Regions;
    sequences: Sequences;
    tracks: Tracks;
}
```

## Example

```json
// example.json
{
    "id": "AARS1",
    "source": "The source of the gene annotation.",
    "species": "The species the gene belongs to.",
    "strand": "-", #TODO: uniform on gene?
    "probes": {...},
    "regions": {...},
    "sequences": {...},
    "tracks": {...}
}
```
