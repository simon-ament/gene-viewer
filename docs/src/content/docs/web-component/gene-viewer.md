The `<gene-viewer />` [Web Component](https://developer.mozilla.org/en-US/docs/Web/API/Web_components) can be used in frontend web applications to visualize descriptions generated by a [`GeneViewer`](/python/gene-viewer) instance.

## Embedding a `<gene-viewer />`

The `<gene-viewer />` custom element can be used inside every HTML document or within [many JavaScript frameworks](https://custom-elements-everywhere.com/) just like any regular HTML element.

A `<gene-viewer />` will fetch the required visualization descriptions from a configurable web server, most likely the backend of your web application. The location of this server **must** be provided via the `viewerServer` property together with the `viewerId` of the `GeneViewer` that was used to generate these JSON descriptions.

Overall, the following properties are available:

- `viewerServer: string`: The server route from which to fetch `GeneViewer`-generated data managed by the [`GeneViewerServer`](/python/gene-viewer-server).
- `viewerId: string`: The unique identifier of the `GeneViewer` that was used to generate the visualization descriptions. Must match the `viewer_id` parameter of that [`GeneViewer`](/python/gene-viewer).
- `parallelProbesets: number`: The number of probesets to display in parallel. The user will be able to select which of the provided probesets to show.
- `scaleFactor: number`: Can be used to scale the visualization according to its width when embedded in your application. A value between 0.5 and 1.5 is recommended.

```html
// example.html

<body>
    <div class="visualization">
        <gene-viewer
            viewerServer="api/viewer"
            viewerId="df83316df83"
            parallelProbesets="2"
            scaleFactor="0.9"
        ></gene-viewer>
    </div>
</body>
```

## Listening to events

Your web application can listen to events dispatched by the `<gene-viewer />` element to update its state and UI according to the user's interactions with the gene visualization. For example, your application could display detailed information on specific probes whenever they are selected in the visualization or highlight the selected probe in a table containing such details.

Such event listeners help make the embedding of the `<gene-viewer />` element feel seamless and can pass on data from within the custom element to your application. For these purposes, the following events will be dispatched:

- `geneViewerReady`: This event is dispatched once the GeneViewer instance has been initialized with a list of displayable genes.
    - The event data contains a reference to the GeneViewer instance as well as a list of available genes.
    - Wait for this event before performing any [method calls](#triggering-changes).
- `geneChanged`: This event is dispatched when the displayed gene changes, either through an user interacting with the `<gene-viewer />` or via a [call](#triggering-changes) to `showGene`.
    - The event data contains the `previousGeneId` and the `newGeneId`. It also contains a dictionary of available probesets and probes (including optional metadata) for this gene.
- `probesetsChanged`: This event is dispatched when the displayed probesets change, either through an user interacting with the `<gene-viewer />` or via a [call](#triggering-changes) to `showProbesets`.
    - The event data contains the `previousProbesetIds` and the `newProbesetIds`.
- `probesSelected`: This event is dispatched when the selected probes change, either through an user interacting with the `<gene-viewer />` or via a [call](#triggering-changes) to `selectProbe`.
    - The event data contains the `previousProbeIds` and the `newProbeIds`.
- `probesetSelected`: This event is dispatched when the selected probeset changes, either through an user interacting with the `<gene-viewer />` or via a [call](#triggering-changes) to `selectProbeset`.
    - The event data contains the `previousProbesetId` and the `newProbesetId`.

```js
// example.js
let geneViewer = document.querySelector("gene-viewer");

geneViewer.addEventListener("geneViewerReady", (event) => {
    const { geneList } = event.details;
})
```

## Styling the `<gene-viewer />`

Custom styling of the `<gene-viewer />` web component is possible via [CSS custom properties](https://lit.dev/docs/components/styles/#customprops). The following properties are available:

- `--gene-viewer-background-color`: The background color of the visualization inside your web application and when exported as an SVG.
- `--gene-viewer-text-color`: The color of all text within the visualization.
- `--gene-viewer-border-color`: The color of all borders within the visualization.

```css
/* example.css */
gene-viewer {
    --gene-viewer-background-color: #d6f6c6;
    --gene-viewer-text-color: #000;
    --gene-viewer-border-color: #888;
}
```
